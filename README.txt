RECOMMENDED FREE OPTION: GITHUB PAGES
1. Create/sign in to a GitHub account owned by the company (or an account the company controls).
2. Create a new PUBLIC repository, e.g. nhlengani-chauke-website.
3. Upload index.html and the entire assets folder into the repository root.
4. Open Settings → Pages.
5. Under Build and deployment, choose “Deploy from a branch”, select the main branch and /(root), then Save.
6. GitHub will provide a free address similar to:
